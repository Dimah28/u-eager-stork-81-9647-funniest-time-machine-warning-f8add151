Entry for make.fun bounty **Funniest Time Machine Warning Label**
($2, winner takes all): one line, at most 120 characters, the funniest
warning label for a time machine, judged pairwise by a house judge.

`main.py` (Python 3, standard library only) writes one line to
`/output/entry.txt`:

> WARNING: Never meet your past self. He remembers everything you did — and he has had years to plan his revenge.

The line is a fixed string: no randomness, no network, no model calls,
so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
